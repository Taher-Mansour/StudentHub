# StudentHub

## 1. Présentation du projet

**StudentHub** est une application mobile Android destinée aux étudiants. Elle permet de consulter les matières, de suivre les tâches à réaliser et de visualiser les prochaines échéances universitaires.

L'objectif est de proposer une interface simple, moderne et facile à utiliser pour faciliter l'organisation du travail universitaire.

## 4. Fonctionnalités principales

- Connexion à l'application.
- Création d'un compte utilisateur.
- Consultation de l'espace étudiant.
- Affichage des matières.
- Suivi des tâches.
- Consultation des prochaines échéances.
- Prise en charge des langues française et anglaise.

## 5. Installation et exécution

1. Installer Android Studio.
2. Télécharger ou cloner le projet depuis GitHub.
3. Ouvrir Android Studio.
4. Sélectionner **File → Open**.
5. Choisir le dossier du projet StudentHub.
6. Attendre la synchronisation Gradle.
7. Connecter un appareil Android ou démarrer un émulateur.
8. Cliquer sur **Run ▶** pour lancer l'application.

## 6. Structure du projet

Le projet contient principalement :

- `java/` : classes Java et logique de l'application.
- `res/layout/` : interfaces XML.
- `res/values/` : ressources françaises.
- `res/values-en/` : ressources anglaises.
- `AndroidManifest.xml` : configuration de l'application.
